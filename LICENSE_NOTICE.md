# Hak bildirimi

Bu projeye otomatik olarak açık kaynak lisansı eklenmemiştir.

Aksi ayrıca belirtilmedikçe TELKİN'e ait hikâye, karakter, görsel, ses, oyun verisi ve özgün kod için tüm haklar eser sahibine aittir. GitHub deposunun herkese açık olması tek başına yeniden kullanım lisansı vermez.

Üçüncü taraf varlık eklenirse lisansı ilgili dosyanın yanında ayrıca tutulmalıdır.
